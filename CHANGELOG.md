# Changelog

All notable changes to moonkafka. Releases are cut from the `feat/phase-7`
branch onward; for the phase-by-phase accumulation see the Git history and
`PLAN.md`.

The `.mbti` package interfaces are regenerated by `moon info` on every
release (see `make info` / the CI `build-test` `.mbti` clean-diff check).

## [0.2.0] - unreleased

First tagged release: the transport + data-plane feature set accumulated
through Phases 0–6, hardened for real-cluster use.

### Added

- **Transport**: KRaft-era Kafka 4.3 protocol framing (compact types,
  zig-zag varints, tagged fields); per-request API version negotiation;
  pipelined broker connections with request timeouts, in-flight caps, and
  reconnect; TLS (incl. custom CA-verified certificates) and SASL
  (PLAIN / SCRAM-SHA-256/512 / OAUTHBEARER).

- **Data plane**:
  - Produce v12/v13 (topic-id addressing, per-record errors, acks 0/1/-1
    with retry + backoff bounded by delivery timeout).
  - Fetch v12–v16 with incremental sessions (KIP-227) and eviction recovery,
    `max_poll_records`/`max_partition_fetch_bytes` caps, pause/resume,
    auto-offset-reset, read_committed filtering, leader-epoch truncation
    detection.
  - Metadata v12/v13 (topic-ids, expiry + error-triggered refresh),
    ListOffsets v10/v11, FindCoordinator v4 (batched), DescribeTopicPartitions
    v0 (paginated).
  - RecordBatch v2 (CRC32C-verified), whole-batch decompression for gzip,
    snappy (xerial), lz4, zstd.

- **Producer**: per-leader connection pool, murmur2 / sticky / round-robin
  partitioning, accumulator with batch_size/linger/buffer_memory accounting,
  background sender, `send`/`send_all` + `SendHandle` callbacks, idempotence
  (InitProducerId + per-partition sequencing + epoch bump on
  UNKNOWN_PRODUCER_ID), and full KIP-98 transactions with transactional
  offset commits.

- **Consumer**: subscribe/assign split, seek family, committed-offset
  tracking (sync/async/autocommit), group membership via KIP-848
  (`ConsumerGroupHeartbeat`) with classic `group_protocol` fallback
  (JoinGroup/SyncGroup/Heartbeat), share groups (KIP-932 `ShareConsumer`).

- **Admin client**: topics, configs, ACLs, quotas, SCRAM credentials, log
  dirs, leaders, reassignments, cluster/controller introspection,
  transactions, and groups listing/describe/delete — with a shared
  retriable-result policy.

- **Telemetry (KIP-714)**: `TelemetryClient` over GetTelemetrySubscriptions /
  PushTelemetry with a pluggable metrics provider.

### Performance (Phase 7)

- `buf.Encoder::with_capacity` preallocation used on the Produce request and
  record-batch finalize hot paths.
- `buf.Decoder::read_bytes_view` — zero-copy `BytesView` slices of the
  backing buffer; `read_bytes` now bulk-copies from the source slice instead
  of a per-byte loop.
- `cmd/main bench-produce` + `bench/bench.sh` throughput harness (produce and
  consume rec/s).

### Tooling

- `Makefile` (build/test/fmt/info/integration/bench/coverage/golden targets).
- `docker-compose.kafka.yml` KRaft cluster (single + 3-broker profiles).
- `.github/workflows/ci.yml`: build+test, fmt + `.mbti` clean diff, Docker
  integration, golden-fixture regeneration.
- Protocol docs in `docs/` (`2`-version negotiation, `3`-consumer groups,
  `4`-transactions, `5`-testing).

### Changed

- `cmd/main` gains `bench-produce <topic> <count> [key] [host] [port]`.

### Fixed

- Decoder bounds checks are computed by subtraction so malformed huge lengths
  raise instead of overflowing / panicking.

## Release checklist

1. `moon info` + commit `.mbti` changes (public API freeze audit).
2. `moon fmt`, `moon test` (all 200+ incl. mock-broker).
3. `make generate-golden` and commit any fixture diffs.
4. `make integration` (Docker Kafka 4.3) once green.
5. Bump `version` in `moon.mod`; update tag (`git tag -s vX.Y.Z`).
6. Update `Makefile`/CI if the harness changed.
